iOS Shortcuts Setup

How to post from your iPhone:
  1. Generate an API key above
  2. Open the Shortcuts app on your iPhone
  3. Create a new shortcut with these steps:
    • Get text from Shortcut Input (or Craft app)
    • Set Variable "Body" to the text
    • Ask for input (title of the post)
    • Set Variable "Title" to the input
    • Get Contents of URL with these settings:
      • URL:
      • Method: POST
      • Headers:
        • X-API-Key: [Your API Key]
        • Content-Type: application/json
      • Request Body: JSON 
        {
  "title": "[Title variable]",
  "body": "[Body variable]"
}
    • Show Result (to see the response)
  4. Save the shortcut and test it!
Security: Keep your API keys private! Anyone with your API key can post to your blog.
